# Day 45 – AI Decision Strategist

## Project Overview

Today I built an **AI Decision Strategist**, an interactive web application that helps users evaluate important decisions using structured analysis, comparison matrices, AI-inspired recommendations, and visual decision support.

The application was created as a single self-contained HTML file with a modern responsive interface.
